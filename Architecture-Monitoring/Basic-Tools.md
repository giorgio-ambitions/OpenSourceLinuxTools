| Tool        | What it shows                           | Example                                      |
| ----------- | --------------------------------------- | -------------------------------------------- |
| `lscpu`     | CPU architecture, cores, threads, cache | `lscpu`                                      |
| `free`      | RAM and swap usage                      | `free -h`                                    |
| `lsblk`     | Disks, partitions, filesystems          | `lsblk -o NAME,SIZE,TYPE,FSTYPE,MOUNTPOINTS` |
| `lspci`     | GPU, Wi-Fi, audio, PCI devices          | `lspci -nn`                                  |
| `lsusb`     | USB devices                             | `lsusb`                                      |
| `uname`     | Kernel and machine architecture         | `uname -a`                                   |
| `lshw`      | Overall hardware hierarchy              | `sudo lshw -short`                           |
| `dmidecode` | BIOS/DMI hardware information           | `sudo dmidecode`                             |
| `sensors`   | Temperatures, fans, voltages            | `sensors`                                    |
| `htop`      | Live CPU, RAM, and process monitoring   | `htop`                                       |
